Growth Capital Academy (GCA) - Student Dashboard & Learning Platform
📖 Overview
Growth Capital Academy (GCA) is a modern, responsive web application and e-learning platform dedicated to financial education, trading strategies, and long-term investor mindset. Designed as a secure members-only portal, the platform provides students with structured curriculum modules, automated progress tracking, live market sessions, and seamless Supabase backend integration.

✨ Key Features
🔒 Secure Authentication System: Robust user sign-up, login, and session management powered by Supabase Auth.

📚 Dynamic Curriculum & Progress Tracker:

Sequential module unlocking (Fundamentals, Trading Strategies, Mindset).

Real-time status synchronization (Completed, Available, Locked) connected directly to a backend database (user_progress).

🔴 Live Trading & Coaching Access: Dedicated hub for interactive live market sessions, real-time analytics, and expert Q&A.

📱 Fully Responsive & Mobile-Optimized: Features a modern dark-mode aesthetic with custom CSS styling, a Google Fonts integration (Inter and Playfair Display), and a mobile-friendly hamburger navigation menu.

🛠️ Community & Support Integration: Quick access channels for mentorship, peer networking via WhatsApp, and direct support.

💻 Tech Stack
Frontend: HTML5, CSS3, JavaScript (ES6 Modules)

Backend / Database: Supabase (PostgreSQL, Auth, Client SDK)

Hosting: GitHub Pages

Design & Typography: Custom UI design incorporating CSS Flexbox/Grid, CSS variables, and Google Fonts.
